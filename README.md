# PagePad (v0.2.0) 📚

> **"PDF를 읽는 페이지마다 Markdown 노트가 따라오는 Windows 데스크톱 메모 앱"**
>
> 논문, 강의자료, 전자책을 PDF로 읽으며 페이지별로 노트를 남기세요. PagePad는 PDF 페이지와 Markdown 파일을 1:1로 연결하고, 모든 데이터를 로컬에만 저장합니다.

> ℹ️ **이 앱은 이전에 `Libri`라는 이름이었습니다.** v0.2.0에서 이름이 PagePad로 바뀌었습니다. 기존에 Libri를 쓰고 계셨다면 **작성한 노트와 설정은 그대로 유지**되며, 앱 안에서 업데이트를 받으시면 됩니다.

---

## ✨ 주요 기능 (Key Features)

- **📄 페이지별 독립 노트 시스템**  
  PDF 뷰어와 마크다운(Markdown) 에디터가 양옆으로 연동됩니다. PDF 페이지를 이동하면 오른쪽 필기창도 해당 페이지 전용 노트로 자동 전환되어 문맥을 잃지 않습니다.
- **📚 표지가 보이는 라이브러리**  
  앱을 열면 내 문서들이 PDF 첫 페이지를 표지로 한 카드로 정리되어 나타납니다. 문서를 폴더로 끌어다 놓아 자유롭게 분류할 수 있습니다.
- **💾 100% 로컬 우선 (Local-First) 구조**  
  유저가 여는 PDF 내용, 텍스트, 필기 노트 등 그 어떤 데이터도 외부 서버로 업로드되지 않으며 오직 본인의 PC에만 안전하게 저장됩니다. 인터넷 연결 없이도 완전히 작동합니다.
- **📝 노트 내보내기 — Markdown & PDF**  
  페이지별로 흩어져 작성된 메모들을 클릭 한 번으로 하나의 문서로 병합할 수 있습니다. 클립보드로 복사하거나 `.md` 파일로 저장해 노션(Notion) 등에 이식할 수 있고, v0.2.0부터는 **작성한 모습 그대로 PDF 파일로도 저장**할 수 있습니다.
- **🔍 문서 검색과 자연스러운 확대·축소**  
  PDF 본문 검색을 지원하며, 정밀 터치패드의 두 손가락 핀치와 마우스 휠 확대·축소가 지금 보고 있는 페이지에만 적용됩니다.

## ⚠️ 다운로드 전 필수 확인 사항

- **지원 OS:** 본 앱은 **Windows 10 / 11 (64비트)** 환경 전용 데스크톱 앱입니다. (맥북 환경은 지원하지 않습니다.)
- **Windows SmartScreen 경고 안내:**  
  개인 개발자가 무료 베타 버전으로 배포하는 단계라 디지털 서명이 되어 있지 않습니다. 파일 실행 시 윈도우에서 "인식할 수 없는 앱"이라는 **파란색 경고창**이 뜰 수 있습니다.  
  바이러스가 없는 안전한 파일이므로 당황하지 마시고 [추가 정보] ➡️ [실행]을 눌러 설치를 진행해 주시면 됩니다. Edge나 Chrome에서 다운로드할 때도 비슷한 경고가 표시될 수 있습니다.
- **설치 위치:** 관리자 권한 없이 현재 사용자 계정에만 설치됩니다.

## 🔒 데이터와 네트워크

- **PDF 내용과 노트는 외부로 전송되지 않습니다.** 열어 본 PDF, 추출된 텍스트, 작성한 노트는 모두 사용자가 지정한 **Vault 폴더** 안에만 저장됩니다.
- **애널리틱스나 크래시 리포트 수집이 없습니다.** 파일 경로나 파일명도 수집하지 않습니다.
- **유일한 네트워크 통신은 업데이트 확인입니다.** 새 버전이 있는지 확인하기 위해 이 저장소의 GitHub Releases에 접속합니다. 그 외의 통신은 하지 않습니다.
